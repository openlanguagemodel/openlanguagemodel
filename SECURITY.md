# Security Policy

## Supported Versions

Security fixes are handled for the current public release line.

| Version | Supported |
|---|---|
| 2.2.x | Yes |
| 2.1.x and earlier | No |

## Reporting A Vulnerability

Please do not open a public issue for a suspected security vulnerability.

Report security concerns privately by emailing:

- Tavish Mankash: <tavish.mankash@gmail.com>
- Keshava Prasad: <keshava.pprsd15@gmail.com>

If GitHub private vulnerability reporting is enabled for this repository, you
may also use the repository's **Report a vulnerability** flow from the Security
tab.

Please include:

- the affected OLM version or commit
- the environment where you found the issue
- a short description of the impact
- reproduction steps or proof of concept, if available
- whether the issue is already public anywhere

We will acknowledge reports as soon as practical, investigate promptly, and
coordinate disclosure before publishing details.
